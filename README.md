# Tradek

Tradek is a web application that simulates a cryptocurrency trading platform, allowing users to buy, sell, and exchange crypto assets in a realistic environment. The platform also features a community forum for user-generated posts and discussions, fostering engagement and knowledge sharing among users.

## Project Overview

As the project lead, I guided a university team of four, each member specializing in areas such as UI/UX design, API integration, and backend development. I coordinated team activities, assigned roles based on individual strengths, and ensured effective collaboration throughout the project lifecycle.

### My Contributions

- Led the team and managed project workflow
- Implemented core market operations: buying, selling, and exchanging crypto assets
- Integrated Firebase and Cloud Firestore for real-time data synchronization
- Developed the forum for user posts and discussions to enhance community engagement
- Collaborated on UI/UX improvements and API integration

## Features

- User authentication and profile management
- Real-time cryptocurrency market simulation
- Buy, sell, and exchange crypto assets
- Interactive charts and market data (Chart.js)
- Community forum for discussions and posts
- Responsive UI/UX design

## Technologies Used

- Next.js
- JavaScript
- HTML & CSS
- Firebase & Cloud Firestore
- Chart.js
- RESTful APIs

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/yourusername/tradek.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Set up Firebase configuration in `/app/db.js`.
4. Run the development server:
   ```bash
   npm run dev
   ```
